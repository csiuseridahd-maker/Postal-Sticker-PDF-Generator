Expected Excel headers
The utility is designed for the uploaded AONE format. It uses RECEIVER NAME, RECEIVER ADD LINE 1/2/3, RECEIVER CITY, RECEIVER STATE/UT, RECEIVER PINCODE, RECEIVER MOBILE NO, RECEIVER EMAILID, BARCODE NUMBER, CODR/COD, VALUE FOR CODR/COD, SENDER NAME, SENDER COMPANY NAME, SENDER ADD LINE 1/2/3, SENDER CITY, SENDER STATE/UT, SENDER PINCODE, SENDER EMAILID and SENDER ALT CONTACT.

Extra headers are ignored. If a field is blank, that line is automatically omitted. Long names/addresses are wrapped and the PDF text is automatically reduced where necessary.
